# User Stories

## Студент

- Как студент, я хочу заполнить профиль (навыки, интересы, направление), чтобы получать персонализированные рекомендации.
- Как студент, я хочу видеть список рекомендованных курсов и навыков с пояснением, почему они полезны.
- Как студент, я хочу получать уведомления в Telegram о новых стажировках и мероприятиях.

## Куратор

- Как куратор, я хочу добавлять и редактировать карточки курсов и стажировок через простую админку.
- Как куратор, я хочу просматривать статистику по студентам (какие рекомендации были показаны, какие действия выполнены).
- Как куратор, я хочу отправлять массовые уведомления студентам по сегментам.

## Разработчик

- Как разработчик, я хочу иметь чёткую структуру проекта, чтобы быстро добавлять новые модули.
- Как разработчик, я хочу использовать Docker для запуска всех сервисов одной командой.
- Как разработчик, я хочу иметь набор тестов для проверки корректности рекомендаций и уведомлений.
