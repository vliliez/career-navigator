# Персональный карьерный AI-навигатор

**Цель проекта:** помочь студентам эффективно планировать обучение и карьеру, ориентируясь на актуальные требования рынка труда.

**Для кого:** студенты, кураторы и преподаватели вузов.

## Ключевые возможности

- Персонализированные рекомендации по курсам и навыкам на основе трендов рынка труда.
- Автообновление информации о востребованных профессиях и навыках.
- Уведомления в Telegram о стажировках, мероприятиях и карьерных возможностях.
- Простой интерфейс для кураторов: добавление/изменение курсов и стажировок, отслеживание прогресса студентов.

## Стек технологий (MVP)

- Frontend: HTML + JS (или React/Vue — по выбору)
- Backend: Python (FastAPI) или Node.js
- ML: scikit-learn / transformers (эмбеддинги и кластеризация)
- Telegram Bot: библиотека для выбранного языка
- База данных: SQLite (для MVP), далее PostgreSQL
- Контейнеризация: Docker + docker-compose
